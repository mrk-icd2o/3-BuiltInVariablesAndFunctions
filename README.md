# Lab 3 - Built in Variables and Functions

You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.

To run your code open `index.html` and then click on the *Go Live* button in the bottom right.  This will open a browser page, and should refresh every time your work saves.

Re-create [this program](https://openprocessing.org/sketch/2867587/embed/?plusEmbedHash=a8b5dfec&userID=175929&plusEmbedTitle=true&show=sketch):

- Randomly coloured circles appear randomly across the screen.

- Pressing a key draws a randomly coloured and sized rectangle, from the origin (0, 0).

- An ongoing count of circles and rectangles in the top left
- Clicking the mouse clears the screen.
